# イカサマポーカー

ブラウザで遊べる、1対1ポーカーです。CPU対戦とルームコードを使ったオンライン対戦に対応しています。5カードドローとテキサスホールデム、4種類のイカサマ、ラウンド中いつでも使えるダウトを実装しています。

## 起動

Node.js 18以降を用意し、リポジトリのルートで次を実行して `http://localhost:8000` を開いてください。

```sh
npm install
npm start
```

オンライン対戦では、ホストがルームを作成して表示されたコードを対戦相手に共有します。相手がコードで参加したら、ホストがゲームを開始します。次のラウンドと新しいゲームの開始もホストが操作します。CPU対戦は従来どおりブラウザ内でプレイできます。

オンライン対戦サーバーはゲーム状態を保持し、各プレイヤーには自分の手札だけを送ります。ルームと対戦データはサーバープロセスのメモリ上にのみ保存され、サーバー再起動で消去されます。アカウント、ランキング、永続化はありません。インターネット上で公開する場合は、このNode.jsサーバーを常時稼働できる環境に配置し、HTTPS/WSSを有効にしてください。

## 遊び方

- モードを選び「ゲーム開始」を押します。各プレイヤーは500チップ、イカサマMPはラウンドごとに5で開始します。
- ベットをチェック、コール、レイズ、フォールドして勝負します。カードの強さは通常のポーカー役で判定します。
- 5カードドローでは各自一度、好きな枚数のカードを交換します。ホールデムではプリフロップ、フロップ、ターン、リバーの順に進行します。
- イカサマはベット手番に関係なくラウンド中に使えます。透視は相手の手札から選んだ3枚（ホールデムでは2枚）を確認でき、3MPを消費します。山札操作と袖の下は2MP、書き換えは4MPです。袖の下はカードを預ける時と戻す時にそれぞれ2MPを消費します。
- ダウトは、相手がこのラウンドに実際に使った種類を当てると成功します。成功すると相手からチップを徴収し、そのラウンドの勝者になります。失敗時はチップを支払い、ラウンド終了まで再度ダウトできません。
- イカサマの使用、MPの変動、使用者や使用時刻はゲームログに記録・表示しません。CPUのMPも表示しません。
- チップが0になるとゲーム終了です。「次のゲーム」で新しい対戦を始められます。

## テスト

```sh
npm test
```

CPU対戦とローカル開発用サーバーを想定したプロトタイプです。公開運用では、サーバーの監視・レート制限・永続ストレージなど、運用環境に応じた追加対策を行ってください。
